Tanya Jawab

Apakah aplikasi ini gratis?

Ya, 100% gratis dan open-source. Anda dapat mendepoy-nya sendiri di Firebase menggunakan repositori GitHub kami.

Bagaimana data saya disimpan?

Data Anda disinkronkan ke database Firebase Cloud yang ter-enkripsi. Sehingga hanya Anda yang memiliki hak akses atas data progres harian Anda.

Bisakah melacak kebiasaan buruk yang ingin saya hindari?

Tentu saja. Anda bisa menetapkan habit dengan kategori "Bad Habit" untuk dihindari harian, dan sistem akan mengawasi jika Anda melanggarnya.
